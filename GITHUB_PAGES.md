# GitHub Pages Deployment

This repository is ready for GitHub Pages.

## Files

- `index.html`
- `styles.css`
- `assets/agentbox-event.png`
- `assets/agentbox-event.webp`
- `.nojekyll`
- `.github/workflows/pages.yml`

## Manual Steps

1. Create a GitHub repository, suggested name: `geeknexus-agentbox`.
2. Push this folder to the repository's `main` branch.
3. In GitHub, go to **Settings** -> **Pages**.
4. Set source to **GitHub Actions**.
5. The included workflow will deploy the static site.
6. Public URL will be:

```text
https://<username>.github.io/geeknexus-agentbox/
```
