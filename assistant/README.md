# 官网公司助手

第一版：右侧悬浮服务栏 + 公开资料问答 + Geekcelia 公众号二维码 + 可编辑邮件咨询摘要。

当前问答使用确定性的关键词检索，未接入大模型，不应宣称可以理解或回答所有问题。无需 API 密钥，无服务端，无新增模型费用。消息只存于当前页面内存，最多保留 20 轮；刷新即清空。邮件需用户自行发送。不得将内部价格、合同、账户凭证或 Wi-Fi 密码放入 knowledge.mjs。

## 接入

在需要显示助手的页面底部加入：

```html
<script type="module" src="/assistant/widget.mjs"></script>
```

首页已有引用。子页面可按需引用；不要部署整个旧站目录覆盖生产环境。上线只同步 assistant/、assets/geekcelia-wechat-qr.jpg 与经线上版本核对的两个首页。中文跟随 html lang="zh-CN"，英文跟随 lang="en"。

## 预览

在网站根目录运行 `python3 -m http.server 8765`，访问 `/assistant/preview.html` 或 `/assistant/preview-en.html`。
