# Geek Nexus AgentBox

Static landing page for `Geek Nexus Technology Limited`.

## GitHub Pages

This site is static HTML/CSS and can be deployed from the repository root.

Suggested public URL after deployment:

```text
https://<username>.github.io/<repository-name>/
```

For a custom domain later, point `www.geeknexus.ai` to the GitHub Pages site in DNS and add the custom domain in repository Pages settings.
